# Evaluación de Historia Argentina reciente

Actividad estática para 4.º año, preparada para publicar con GitHub Pages.

## Publicación

1. Crear un repositorio público en GitHub.
2. Subir `index.html` a la raíz del repositorio.
3. Abrir **Settings > Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main`, carpeta `/ (root)` y guardar.

La dirección quedará con este formato:

`https://USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

## Funcionamiento

- 20 preguntas, una por pantalla.
- Nota automática sobre 10.
- Sin regreso a preguntas anteriores.
- El progreso se conserva si se recarga la página.
- El intento final queda bloqueado en ese navegador.
- La constancia final contiene nombre, curso, nota, fecha y código.

## Límite técnico

El bloqueo utiliza el almacenamiento del navegador. Puede eludirse mediante otro dispositivo, otro navegador o una ventana privada. Para registrar automáticamente las notas se necesita agregar una base de datos o un servicio como Google Apps Script.
